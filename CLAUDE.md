# AACraft Web — craft calculator page

Read `SPEC.md` first — it is the contract for data format, engine semantics and UI.

- Single static page (Vite + vanilla TS), to be embedded into the sermeatbal site. No backend.
- Source game data stays in `../AACraft/` (read-only). `public/data.json` is generated by
  `npm run data` and is gitignored — never hand-edit it.
- The calculator is deterministic: no RNG/roll simulation, `products[].rate` is ignored.
- Engine (`src/engine.ts`) is pure and DOM-free; all business logic changes need a vitest case.
- E2E: `e2e/` with @playwright/test (specs/ + pages/ page objects), run via `npm run e2e`.
- Commit messages: short imperative subject, no Co-Authored-By lines.
